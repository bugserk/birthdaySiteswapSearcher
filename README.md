# birthdaySiteswapSearcher
誕生日に含まれる数字を使用したジャグリング可能なサイトスワップを探すウェブアプリ  
https://bugserk.github.io/birthdaySiteswapSearcher/

## 工夫
誕生日がジャグリング可能なサイトスワップかどうか調べると、多くの場合ジャグリング不可能になってしまう。  
本アプリでは以下2つの工夫により、誕生日に含まれる数字を使ったジャグリング可能なサイトスワップを生成する。  
これにより、366個の日付のうち、すべてで1つ以上、348個で2つ以上のジャグリング可能なサイトスワップを発見できる。

### マルチスローの使用
複数の数字をマルチスローとしてまとめることでパターン数を増やし、ジャグリング可能なパターンを見つけやすくする。  
なお、すべての数字を1つのマルチスローにまとめると、必ずジャグリング可能となるため、これによりすべての日付でジャグリング可能なパターンが1つ以上見つかることが保障される。
#### 例
12月18日を数列化した、1218はジャグリング不可である。  
しかし、マルチスローを使用することにより、以下のパターンも検証対象となる。  
[12]18, [121]8, [1218], 1[21]8, 1[218], 12[18], [12][18]  
これらのジャグリング可能性を調べることにより、以下の新たなジャグリング可能なパターンが得られる。  
1[21]8, 1[218], [12][18]


### 数字のアルファベット化
隣合う2つの数字をアルファベット1文字にまとめることにより、パターンを増やし、ジャグリング可能なパターンを見つけやすくする。
### 例
11月22日を数列化した1122はジャグリング不可である。  
しかし、数字のアルファベット化を使用すると、11→b, 12→c, 22→mと置き換えられるため、以下のパターンも検証対象となる。  
b22, 1c2, 11m, bm  
これらのジャグリング可能性を調べることにより、以下の新たなジャグリング可能なパターンが得られる。  
b22, 11m
